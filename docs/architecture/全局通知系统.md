# 全局通知系统 (NotificationCenter)

## 📋 概述

全局通知系统是一个类似Flutter SnackBar的轻量级通知组件，为Questech应用提供统一的用户反馈机制。

## 🏗️ 架构设计

### 核心组件
- **NotificationCenter**: 全局单例管理器
- **NotificationItem**: 单个通知项组件
- **NotificationContainer**: 通知容器组件

### 文件结构
```
src/
├── components/
│   └── common/
│       ├── NotificationCenter.js     # 全局管理器
│       ├── NotificationItem.js        # 通知项组件
│       └── NotificationContainer.js   # 通知容器
└── assets/
    └── styles/
        └── components/
            └── notification.css       # 通知样式
```

## 🎯 设计原则

### 1. 显示规则
- **位置**: 固定在屏幕右上角
- **堆叠**: 垂直堆叠，新通知在上方
- **最大数量**: 同时最多3个通知
- **自动移除**: 超出数量时移除最旧的

### 2. 持续时间
- **成功**: 3秒
- **信息**: 2秒  
- **警告**: 4秒
- **错误**: 5秒

### 3. 交互行为
- **自动消失**: 倒计时结束自动移除
- **手动关闭**: 点击×按钮立即关闭
- **暂停计时**: 鼠标悬停暂停倒计时
- **点击回调**: 支持点击通知触发回调

## 🔧 API 设计

### 基础用法
```javascript
// 简单消息
NotificationCenter.success('操作成功');
NotificationCenter.error('操作失败');
NotificationCenter.warning('警告信息');
NotificationCenter.info('提示信息');

// 通过EventBus触发
eventBus.emit('notification:show', {
    message: '文件上传完成',
    type: 'success'
});
```

### 完整配置
```javascript
NotificationCenter.show({
    title: '操作结果',           // 标题（可选）
    message: '详细信息',         // 消息内容
    type: 'success',            // 类型: success|error|warning|info
    duration: 3000,             // 持续时间（毫秒）
    closable: true,             // 是否显示关闭按钮
    onClick: () => {},          // 点击回调
    onClose: () => {}           // 关闭回调
});
```

### 管理方法
```javascript
// 清除所有通知
NotificationCenter.clear();

// 清除指定类型
NotificationCenter.clearByType('error');

// 获取当前通知数量
NotificationCenter.getCount();
```

### 动画效果
- **进入**: 从右侧滑入 + 淡入
- **退出**: 向右滑出 + 淡出
- **堆叠**: 平滑的位置过渡

## 🔄 工作流程

```
触发通知 → 创建NotificationItem → 添加到容器 → 显示动画 → 倒计时 → 移除动画 → 销毁
```

### 详细流程
1. **触发**: 组件调用API或EventBus事件
2. **验证**: 检查参数有效性
3. **创建**: 实例化NotificationItem
4. **队列**: 添加到通知队列，检查数量限制
5. **渲染**: 渲染到NotificationContainer
6. **动画**: 执行进入动画
7. **计时**: 开始倒计时（支持暂停/恢复）
8. **移除**: 时间到或手动关闭时执行退出动画
9. **清理**: 从DOM和队列中移除

## 🚀 集成方式

### 1. 应用初始化
```javascript
// App.js
import { NotificationCenter } from './components/common/NotificationCenter.js';

class App {
    async init() {
        // 初始化通知管理器
        this.notificationCenter = new NotificationCenter({
            eventBus: this.eventBus,
            container: document.body
        });
        
        // 注册为全局服务
        this.services.set('notification', this.notificationCenter);
    }
}
```

### 2. 组件中使用
```javascript
// 任意组件中
export class SomeComponent {
    handleSuccess() {
        // 方式1: 直接调用
        if (window.app) {
            const notification = window.app.getService('notification');
            notification.success('操作成功');
        }
        
        // 方式2: 通过EventBus
        this.eventBus.emit('notification:show', {
            message: '操作成功',
            type: 'success'
        });
    }
}
```

## 📝 使用示例

### 常见场景
```javascript
// 文件上传成功
NotificationCenter.success('文件上传完成');

});
```
