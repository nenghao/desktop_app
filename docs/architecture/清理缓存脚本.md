# 清理缓存脚本

## 问题诊断

如果智能体列表无法显示，很可能是因为本地缓存中存储的是旧格式数据（`global_version`, `agents_hash`），而新代码期望的是新格式（`version`, `last_updated`）。

---

## 快速解决方案

### 方法 1: 在浏览器控制台执行（推荐）

打开浏览器控制台（F12），执行以下代码：

```javascript
// 1. 查看当前缓存的版本信息
console.log('当前版本缓存:', localStorage.getItem('Questech_agents_versions'));

// 2. 清除版本缓存
localStorage.removeItem('Questech_agents_versions');
console.log('✅ 版本缓存已清除');

// 3. 可选：清除所有智能体相关缓存
localStorage.removeItem('Questech_agents_data');
localStorage.removeItem('Questech_agents_categories');
console.log('✅ 所有智能体缓存已清除');

// 4. 刷新页面
location.reload();
```

---

### 方法 2: 清除所有 Questech 缓存

```javascript
// 清除所有以 Questech_ 开头的缓存
Object.keys(localStorage).forEach(key => {
  if (key.startsWith('Questech_')) {
    console.log('删除缓存:', key);
    localStorage.removeItem(key);
  }
});

console.log('✅ 所有 Questech 缓存已清除');
location.reload();
```

---

### 方法 3: 使用开发者工具

1. 打开浏览器开发者工具（F12）
2. 切换到 **Application** 标签（Chrome）或 **Storage** 标签（Firefox）
3. 在左侧找到 **Local Storage**
4. 选择你的网站域名
5. 找到以下键并删除：
   - `Questech_agents_versions`
   - `Questech_agents_data`
   - `Questech_agents_categories`
6. 刷新页面（F5）

## 详细诊断步骤

### 1. 检查缓存格式

```javascript
// 查看版本缓存
const versionCache = localStorage.getItem('Questech_agents_versions');
if (versionCache) {
  const data = JSON.parse(versionCache);
  console.log('版本缓存内容:', data);
  
  // 检查是否是旧格式
  if (data.global_version || data.agents_hash) {
    console.error('❌ 检测到旧格式缓存！');
    console.log('旧格式字段:', {
      global_version: data.global_version,
      agents_hash: data.agents_hash
    });
  }
  
  // 检查是否是新格式
  if (data.version || data.last_updated) {
    console.log('✅ 检测到新格式缓存');
    console.log('新格式字段:', {
      version: data.version,
      last_updated: data.last_updated
    });
  }
} else {
  console.log('ℹ️ 无版本缓存');
}
```

### 2. 检查智能体数据缓存

```javascript
// 查看智能体数据缓存
const agentsCache = localStorage.getItem('Questech_agents_data');
if (agentsCache) {
  const data = JSON.parse(agentsCache);
  console.log('智能体数据缓存:', {
    version: data.version,
    dataKeys: Object.keys(data.data || {}),
    timestamp: data.timestamp
  });
} else {
  console.log('ℹ️ 无智能体数据缓存');
}
```

### 3. 手动触发更新

```javascript
// 清除缓存后手动触发更新
localStorage.removeItem('Questech_agents_versions');

// 等待服务初始化
setTimeout(async () => {
  const agentDataService = window.agentDataService;
  if (agentDataService) {
    console.log('🔄 手动触发更新检查...');
    const result = await agentDataService.checkAndUpdateAgents();
    console.log('更新结果:', result);
  } else {
    console.error('❌ agentDataService 未初始化');
  }
}, 1000);
```

## 预防措施

为了避免将来出现类似问题，建议在代码中添加缓存版本迁移逻辑：

### 添加缓存迁移代码

在 `DataCacheService.js` 的 `getAgentVersions()` 方法中添加：

```javascript
getAgentVersions() {
  try {
    const versionData = this.storageService.get(this.CACHE_KEYS.AGENTS_VERSIONS);

    if (!versionData) {
      return null;
    }

    // 检测并迁移旧格式
    if (versionData.global_version || versionData.agents_hash) {
      console.warn('⚠️ [DataCacheService] 检测到旧格式缓存，自动清除');
      this.storageService.remove(this.CACHE_KEYS.AGENTS_VERSIONS);
      return null;
    }

    return versionData;
  } catch (error) {
    console.error('❌ [DataCacheService] 获取智能体版本信息失败:', error);
    return null;
  }
}
```

## 常见问题

### Q1: 清除缓存后还是看不到智能体列表？

**检查步骤：**
1. 打开浏览器控制台，查看是否有错误信息
2. 检查网络请求是否成功（Network 标签）
3. 确认后端 API 返回的数据格式正确
4. 查看 `agentDataService` 的日志输出

**诊断命令：**
```javascript
// 检查服务状态
console.log('agentDataService:', window.agentDataService);
console.log('agentsData:', window.agentDataService?.agentsData);

// 手动初始化
await window.agentDataService?.initialize();
```

### Q2: 如何确认后端返回的格式正确？

**检查命令：**
```javascript
// 手动请求版本接口
const response = await fetch('/api/v2/agent/versions');
const data = await response.json();
console.log('版本接口返回:', data);

// 检查字段
if (data.data.version && data.data.last_updated) {
  console.log('✅ 后端格式正确');
} else {
  console.error('❌ 后端格式错误，返回的字段:', Object.keys(data.data));
}
```

### Q3: 清除缓存后需要重新下载智能体吗？

**不需要。** 清除的只是版本信息和列表数据的缓存，已下载的智能体文件（executables 和 librarys）不会被删除。

## 自动化清理脚本

如果需要在应用启动时自动清理旧格式缓存，可以在 `App.js` 或 `DataCacheService.js` 初始化时添加：

```javascript
// 在应用启动时执行
function cleanupOldCache() {
  try {
    const versionCache = localStorage.getItem('Questech_agents_versions');
    if (versionCache) {
      const data = JSON.parse(versionCache);
      
      // 检测旧格式
      if (data.global_version || data.agents_hash) {
        console.warn('🧹 [Cleanup] 检测到旧格式缓存，自动清理...');
        localStorage.removeItem('Questech_agents_versions');
        localStorage.removeItem('Questech_agents_data');
        localStorage.removeItem('Questech_agents_categories');
        console.log('✅ [Cleanup] 旧缓存已清理');
      }
    }
  } catch (error) {
    console.error('❌ [Cleanup] 清理缓存失败:', error);
  }
}

// 在应用初始化时调用
cleanupOldCache();
```

## 总结

**最快的解决方案：**
1. 打开浏览器控制台（F12）
2. 执行：`localStorage.removeItem('Questech_agents_versions')`
3. 刷新页面：`location.reload()`

这样就能清除旧格式的缓存，让应用使用新格式重新获取数据。
