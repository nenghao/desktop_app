# 聊天输入框展开动画优化

布局结构
┌─────────────────────┐ ← 容器 (max-height: 200px)
│  ┌───────────────┐  │
│  │  Textarea     │  │ ← max-height: 120px
│  │  [可滚动]     │  │   flex-shrink: 0
│  │     ▲         │  │
│  │     │滚动     │  │
│  └───────────────┘  │
│                     │
│  ┌───────────────┐  │
│  │ [+] [...] [→] │  │ ← height: 40px
│  └───────────────┘  │   flex-shrink: 0
└─────────────────────┘   固定底部

## 问题描述

原有的输入框展开/折叠动画存在以下问题：
1. 展开时动画突兀，有"直接冲上去"的感觉
2. `expand-button` 和 `send-button` 在展开/折叠时会上下跳动
3. 按钮从中间位置突然跳到底部，产生回弹效果
4. 整体视觉效果不够自然流畅

## 优化方案

### 核心思路
将布局锚点从"中间对齐"改为"底部对齐"，让所有元素以底部为基准进行定位，这样展开时：
- 按钮保持在底部不动
- 输入框向上扩展
- 控制行从下方平滑滑入

### 1. 容器对齐方式调整

**文件**: `src/styles/components/chat-input.css:35-36`

```css
/* 修改前 */
justify-content: center;
transition: var(--app-transition);

/* 修改后 */
justify-content: flex-end; /* 底部对齐 */
transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1); /* 平滑过渡曲线 */
```

**原因**: 使用 `flex-end` 让内容从底部开始布局，展开时内容向上生长

### 2. 展开/发送按钮定位优化

**文件**: `src/styles/components/chat-input.css:52-92`

#### 展开按钮
```css
/* 默认状态：始终固定在底部 */
.expand-button {
  position: absolute;
  bottom: var(--spacing-1); /* 固定底部位置 */
  left: var(--spacing-2);
  transition: background-color 0.2s ease, box-shadow 0.2s ease, transform 0.2s ease;
}

/* 折叠状态：居中显示 */
.chat-input-wrapper.collapsed .expand-button {
  bottom: 50%;
  transform: translateY(50%); /* 通过transform居中 */
}
```

**关键改进**:
- 默认定位在底部（展开状态）
- 折叠时通过 `transform: translateY(50%)` 移动到中间
- 避免了 `top` 和 `bottom` 的突然切换

#### 发送按钮
```css
/* 默认状态：始终固定在底部 */
.send-button {
  left: auto;
  right: var(--spacing-2);
  bottom: var(--spacing-1);
}

/* 折叠状态：居中显示 */
.chat-input-wrapper.collapsed .send-button {
  bottom: 50%;
  transform: translateY(50%);
}
```

### 3. 输入框定位优化

**文件**: `src/styles/components/chat-input.css:108-127`

```css
/* 展开状态：静态定位 */
.chat-input.expanded {
  max-height: 180px;
  position: static;
  padding-bottom: var(--spacing-2);
  opacity: 1;
}

/* 折叠状态：绝对定位居中 */
.chat-input.collapsed {
  position: absolute;
  bottom: 50%;
  transform: translateY(50%);
  margin-left: 40px;
  margin-right: 40px;
  width: calc(100% - 104px);
}
```

### 4. 控制行平滑滑入

**文件**: `src/styles/components/chat-input.css:210-222`

```css
/* 默认状态：隐藏在下方 */
.control-row {
  height: 0;
  opacity: 0;
  overflow: hidden;
  transform: translateY(-10px); /* 向上偏移10px */
  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

/* 展开状态：滑入显示 */
.chat-input-wrapper.expanded .control-row {
  height: 40px;
  opacity: 1;
  transform: translateY(0); /* 归位 */
}
```

**效果**: 控制行从下方平滑滑入，有轻微的"浮起"动画

### 5. 按钮呼吸动画适配

**文件**: `src/styles/components/chat-input.css:158-187`

```css
/* 折叠状态的呼吸动效 */
@keyframes breathing-collapsed {
  0%, 100% {
    opacity: 1;
    transform: translateY(50%) scale(1); /* 保持居中 */
  }
  50% {
    opacity: 0.7;
    transform: translateY(50%) scale(0.95);
  }
}

/* 展开状态的呼吸动效 */
@keyframes breathing-expanded {
  0%, 100% {
    opacity: 1;
    transform: scale(1); /* 无需translateY */
  }
  50% {
    opacity: 0.7;
    transform: scale(0.95);
  }
}
```

## 技术细节

### 过渡曲线选择
使用 `cubic-bezier(0.4, 0, 0.2, 1)` 缓动函数：
- 开始时较慢（0.4）
- 中间加速（0, 0.2）
- 结束时减速（1）
- 提供自然的"ease-out"效果

### Transform vs Position
- **Transform**: 使用 GPU 加速，性能更好，动画更流畅
- **Position**: 可能触发重排（reflow），性能较差
- 优先使用 `transform: translateY()` 而非改变 `top/bottom` 值

### 布局策略
```
折叠状态 (min-height: 50px)
┌─────────────────────────────────┐
│  [+]   [Input]           [Send] │  ← 所有元素居中
└─────────────────────────────────┘

展开状态 (height: auto)
┌─────────────────────────────────┐
│         [Input Area]            │
│                                 │  ← 输入框向上扩展
│  [+]  [Controls]        [Send]  │  ← 按钮保持底部不动
└─────────────────────────────────┘
```

## 视觉效果

### 展开动画
1. 输入框平滑向上扩展
2. 圆角从 `50px`（胶囊形）过渡到 `var(--border-radius-2xl)`
3. 控制行从底部滑入，透明度从 0 到 1
4. expand-button 和 send-button 保持在原位不动
5. 整体过渡时间 300ms，使用自然缓动曲线

### 折叠动画
1. 输入框平滑向下收缩
2. 圆角从普通圆角过渡到胶囊形
3. 控制行向下滑出，透明度从 1 到 0
4. 按钮平滑移动到中间位置
5. 视觉上感觉是"整体下沉"

## 性能优化

1. **使用 Transform**: 所有位置变化都通过 `transform` 实现，避免触发重排
2. **合理的过渡时间**: 300ms 提供流畅感但不拖沓
3. **GPU 加速**: 使用 `will-change` 或 `transform3d` 可进一步优化
4. **Pointer Events**: 折叠时禁用控制行的指针事件，避免误触

## 测试建议

1. **点击展开按钮**: 观察输入框是否平滑向上扩展，按钮是否保持不动
2. **快速切换**: 连续点击展开/折叠，检查动画是否流畅无卡顿
3. **输入内容**: 输入多行文本自动展开时，检查动画是否自然
4. **不同屏幕**: 测试移动端和桌面端的表现
5. **深色/浅色模式**: 确认两种主题下动画效果一致
