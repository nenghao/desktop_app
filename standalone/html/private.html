概要

奇境探索（以下简称“开发者”）一直以来高度重视个人信息和隐私的保护，充分理解个人信息对您来说至关重要，开发者承诺将严格遵守法律法规，遵循隐私保护原则，竭尽全力保护您的个人信息安全，为您提供安全、可靠的服务。开发者致力于在为您提供优质产品和服务的同时，全方位守护您的个人信息和隐私安全。为了向您清晰地说明开发者如何收集、使用、存储、共享和保护您的个人信息，以及您所享有的相关权利，开发者制定了《奇境探索隐私政策》（以下简称“本政策”），以便帮助您作出适当的选择。

在正式开始使用开发者的产品和服务之前，请您注意，本政策为规范双方权利义务关系的重要文件，务必仔细阅读所有条款，特别是开发者使用加粗等方式提示的条款。如果您对本政策内容存在任何疑问、意见或建议，可以与开发者联系。如果您不理解或不同意本政策的部分或全部内容，请暂勿使用开发者的产品和服务。一旦您开始使用开发者的产品和服务，即表示您已充分理解并同意接受本政策的所有条款。

请您放心，开发者会始终遵循最小必要原则（最小影响、最小范围、最短时间）仅在您使用特定功能时，为实现向您提供服务的目的，处理您的相关个人信息。

您可以通过阅读以下概要来了解开发者的隐私政策：

  1. 个人信息的收集和使用；
  2. 如何使用cookie和同类技术；

  4. 信息的存储；
  5. 信息安全；

1. 个人信息的收集和使用

收集和使用的原则：在您使用产品服务的过程中，开发者会遵循合法、正当、最小必要、公开透明的原则，按照如下方式收集您在使用服务时主动提供的或因为使用服务而产生的信息，用以向您提供服务。

1.1 开发者收集信息的方式

开发者会按照以下两种方式收集您的个人信息：

  • 您主动提供：
    • 当您注册奇境探索的账号或使用产品和服务时，您可能需要提供一些基本信息，如电话号码、电子邮件等。
    • 在使用过程中，您可能会主动上传文字、图片、音频、视频或其他文件等内容。
    • 当您向开发者反馈问题、提出建议、投诉或请求客服支持时，您可能会提供相关的个人信息。
    • 当您使用部分功能时，您可能会提供针对该特定功能实现所需要的相关个人信息。
  • 开发者主动收集：
    • 开发者会通过技术手段自动收集您的设备信息，如设备型号、操作系统版本、唯一设备标识符等。
    • 服务器会自动记录您的使用情况，包括访问时间、IP地址等。
    • 如果您使用了基于位置的服务，开发者会收集您的位置信息。
    • 开发者可能会使用Cookie和类似技术来了解您的使用习惯，以便提供更个性化的服务。

1.2 收集信息的种类和目的

  • 开发者可能会需要您授权的权限如下：
    • 相机和图库的访问权限：您主动拍摄照片时，开发者会请求您授权相机权限。如果您拒绝授权，将无法拍摄照片或上传图片，但不影响您使用应用的其他功能。
  • 开发者可能会收集的信息种类如下：
    • 账号信息：您在注册和使用开发者的产品和服务时提供的个人信息，如手机号码、头像、电子邮箱地址等。这些信息用于创建和管理您的账号，确保您能够顺利访问和使用开发者的服务。
    • 对话信息：您在使用开发者的产品和服务过程中输入和产生的文本、语音、图片、视频等内容。这些信息有助于开发者优化模型，并了解您的需求和偏好，以便为您提供更精准的服务和支持。
    • 设备信息和日志信息：您在使用开发者产品和服务时所用设备的相关数据，如设备型号、操作系统版本、唯一设备标识符、MAC地址、用户ID、对话ID、对话内容，以及IP地址、浏览器类型、电信运营商、使用语言、访问日期和时间等。收集这些信息是为了软件与服务的合法及安全运行，保障运营的质量及效率。
    • 身份信息：您进行投诉，或者其他需要验证个人身份的场景时，开发者可能会向您收集您的身份信息。
    • 其他信息：为了您更好地使用开发者部分产品功能，开发者可能会收集您的位置信息等。

1.3 使用信息的方式和目的

在使用您的个人信息时，开发者的目标是在遵守所有相关法律法规的前提下，尽力为您提供最佳的服务体验。

1.3.1 向您提供基本的服务功能：

  • 账号注册和登录：
    • 当您使用手机号验证码登录时，开发者将收集您的手机号码、验证码用于登录账号时验证您的身份。
    • 当您使用操作系统独有的登录（例如iOS/macOS系统的Sign in with Apple）进行注册登录时，开发者将收集登录平台提供的唯一标识、昵称、邮箱用于验证和展示您的身份。对于邮箱由您登录时选择是否提供真实邮箱还是虚拟邮箱，您提供的是虚拟邮箱的，开发者将收集您提供的邮箱。
    • 当您通过App端注册和登录时，基于开发者与通信运营商的合作，您可选择使用“一键登录”快速注册和登录。当您选择此方式时，开发者会在取得您同意的前提下，将您设备中的手机号码作为您账号的绑定号码，并免于密码或动态验证码核验。
    • 您也可以使用第三方账号（如微信）注册和登录。开发者会在取得您同意的前提下，获取您在第三方平台使用的公开信息（头像、昵称以及您授权的其他信息），用于与开发者产品和服务的账号绑定，以便您直接登录。如果注册所需信息有部分缺失，开发者会向您补充收集信息。
    • 您登录时提供的有效信息将作为开发者与您取得联系的方式之一，包括但不限于接收通知（如政策更新、服务变更等）。
  • 对话及历史对话查询：
    • 开发者的产品和服务的正常使用依赖于您输入的内容，因此开发者需要收集并使用您输入的文字、图片或其他格式的文件，从而为您提供对话服务。
    • 为实现并保证体验的连续性，开发者需要收集并使用历史对话信息。您可以删除您的历史对话信息。
    • 保证产品和服务的正常运行：为保证产品和服务的正常开展，开发者可能会收集并使用非通信内容数据（包括日志数据、设备信息、Cookie和同类技术信息，如：IMEI、Android ID、Android OAID、HarmonyOS OAID、IDFA、语言设置、产品版本号、操作系统版本、IP地址、产品版本号）
    • 当您使用对话功能时，您可以通过对话框主动发送或授权开发者获取文字、文件、图片、按键操作指令等信息（具体以您输入的为准，以下简称“输入信息”），开发者将基于您在奇境探索服务界面中选择的大语言模型，对输入信息进行处理并向您输出生成内容，以提供智能对话服务。
    • 开发者可能通过网页、PC客户端、应用程序等多种形式提供服务，为提升您在奇境探索各端的使用体验，同一账号的历史对话记录会在奇境探索不同客户端之间进行同步。

1.3.2 服务体验的优化与改进：

  • 在您使用开发者的产品和服务时，您可以进行点赞、点踩、反馈、分享等操作，开发者将收集您的操作和评价内容，以便改进开发者的服务体验。同时，在经安全加密技术处理、严格去标识化且无法重新识别特定个人的前提下，开发者也会将您输入输出的内容用来优化模型，进而增进您的服务体验。
  • 在您向开发者进行投诉时，您需要按照法律规定主动提供您的身份信息和联系方式，以便开发者有效处理投诉事宜。

1.4 特别提示

请您谨慎上传您的个人信息，尤其是敏感个人信息。

如果信息无法单独或结合其他信息识别到您的个人身份，则其不属于法律意义上您的个人信息。当您的信息可以单独或结合其他信息识别到您的个人身份时，或开发者将无法与任何其他特定个人信息建立联系的数据与您的个人信息结合使用时，开发者会严格按照本政策处理这些信息。

您上传任何内容（包括但不限于正常输入、反馈或联系开发者时提供的文字、图片或其他格式的文件）时，请特别留意这些内容是否包含或涉及任何第三方的个人信息或者涉密信息等不适当的信息。这包括但不限于姓名、联系方式或其他个人识别信息。在提交此类信息前，您有责任确保已经获得了所有必要的合法授权，以避免无意中泄露他人隐私或者侵犯其合法权益。

希望您理解，根据个人信息保护法的规定，下列情形无需事先获得您的同意：

  1. 为订立、履行合同所必需：当您与开发者订立或履行合同时，可能需要处理您的个人信息，例如为了完成交易或提供服务。
  2. 为履行法定职责或者法定义务所必需：当开发者需要遵守法律法规，履行法定职责或义务时，可能需要处理您的个人信息，例如与国家安全、刑事侦查、审判和执行等有关的或响应政府部门指示所必需。
  3. 为应对突发公共卫生事件，或者紧急情况下为保护自然人的生命健康和财产安全所必需：在紧急情况下，为了保护您或他人的生命、健康和财产安全，可能需要处理您的个人信息。
  4. 为公共利益实施新闻报道、舆论监督等行为，在合理的范围内处理个人信息：为了公共利益，如新闻报道和舆论监督，可能在合理范围内处理您的个人信息。
  5. 在合理的范围内处理个人自行公开或者其他已经合法公开的个人信息：如果您已经公开了某些个人信息，或者这些信息已经合法公开，开发者可能在合理范围内处理这些信息。
  6. 法律、行政法规规定的其他情形：其他法律法规规定的情形。

2. 如何使用Cookie和同类技术

2.1 开发者使用Cookie和同类技术来提升您的用户体验，优化服务性能，并为您提供更加个性化的服务。具体而言，开发者使用Cookie的目的包括但不限于：

  • 记住您的偏好设置：例如语言设置、界面主题，以便您下次访问时无需重新设置。
  • 分析网站流量和用户行为：通过收集匿名数据帮助开发者了解用户的行为模式，以改进网站功能和服务质量。
  • 增强安全性：用于识别和防止潜在的安全威胁，保护您的账号和个人信息免受未经授权的访问。

2.2 开发者不会将 Cookie 和同类技术用于本政策所述目的之外的任何用途。

2.3 开发者尊重您的权利，您可以根据自己的需要管理或禁用Cookie。大多数浏览器允许您直接在设置中管理Cookie。您可以选择接受所有Cookie、仅接受某些类型的Cookie或完全拒绝所有Cookie。如果您希望删除已存储的Cookie，也可以通过浏览器的设置选项完成这一操作。请注意，禁用某些Cookie可能会严重影响您的用户体验。

3. 委托处理、共享、转移、公开披露您的个人信息

3.1 委托处理

开发者可能会委托第三方服务提供商（如开发者的技术服务方等授权合作伙伴）处理您的个人信息，以便他们为开发者提供技术支持、数据分析等服务。开发者仅会在采用行业通用的安全技术前提下，基于合法、正当、必要、特定、明确的目的委托其处理您的信息。受托方只能接触到为履行其职责所必需的个人信息，并且必须遵守开发者的指示和本政策的规定，不得超出约定的目的范围使用这些信息。

3.2 共享

除了获得您明确同意，或者依照法律规定无需获得您同意的情况外，开发者可能会与合作方（包括开发者的关联方与其他第三方）共享您的个人信息，以实现软件工具开发包（SDK）等功能的正常使用。

如果您想了解哪些第三方会基于何种目的、使用何种方式共享您的信息，可以参阅《第三方信息共享清单》

3.3 转让

随着奇境探索业务的持续发展，开发者有可能进行合并、收购、资产转让等交易，开发者将告知您相关情形，按照法律法规及不低于本政策所要求的标准继续保护或要求新的个人信息处理者继续保护您

3.4 公开披露

除了获得您明确同意，或者依照法律规定无需获得您同意的情况外，开发者不会公开披露您的个人信息。

4. 信息的存储

4.1 存储地点

开发者将您的个人信息将托管于中国境内的[阿里云华南1]地域。除非取得您的单独同意，并且符合国家相关法律法规的规定，开发者不会向境外提供您的任何个人信息。

4.2 存储期限

除国家法律法规另有规定外，开发者仅在为实现服务目的所必需的时间内保留您的个人信息。当开发者的产品和服务发生停止运营的情形时，开发者将采取短信、公告等形式通知您，并在合理的期限内匿名化处理或彻底删除您的个人信息，法律法规另有规定的除外。

5. 信息安全

5.1 开发者深知个人信息的安全保密对于您至关重要。开发者会尽可能避免收集无关的用户信息，并采取不低于业内一般性标准的技术和组织措施来保护您的个人信息免受未经授权的访问、公开披露、使用、修改、损坏或丢失，包括但不限于：

基础设施依赖：用户数据存储于阿里云OSS对象存储服务，默认启用服务器端加密（SSE-S3）；数据库采用阿里云RDS MySQL服务，启用TDE透明数据加密。

数据加密/传输：通过阿里云SSL证书服务实现HTTPS传输加密，TLS协议版本不低于1.2，支持AES_128_GCM等加密套件。

安全托管：服务器部署于阿里云华南1地域，默认启用云防火墙基础防护与DDoS攻击清洗功能，系统漏洞修复依赖阿里云云安全中心自动更新。

5.2 针对敏感个人信息，开发者会在处理前取得您的单独同意，并采取更加严格的安全措施。

5.3 请您特别注意，由于技术手段与管理手段的局限性，互联网环境并非百分之百安全。有些信息一旦泄露，其后果是不可逆的。尽管开发者采取了上述措施并竭力提升安全水平，也无法担保绝对的安全。开发者强烈建议您与开发者一道采取更为积极的安全措施，拒绝出借账号、透露验证码、上传敏感信息等高危操作。

5.4 开发者制定了网络安全事件应急预案，如果不幸发生个人信息泄露等安全事件，开发者会立即启动应急预案，采取措施防止危害扩大。开发者会及时将安全事件的基本情况、可能的影响以及开发者已经采取的补救措施以电话、推送通知等方式告知您。难以逐一告知个人信息主体时,开发者会采取合理、有效的方式发布公告。同时，开发者也会将有关情况上报至监管部门，配合调查，追究责任方的法律责任。

6. 您的权利

开发者非常重视并保障您个人信息相关权利。在您使用奇境探索期间，为了让您更便捷地查询、复制、更正、补充、删除您的个人信息，或撤回个人信息处理的授权，您可参考下面的指引进行操作。此外，开发者还设置了投诉举报渠道，您的意见将会得到及时的处理。

请注意，不同操作系统、本服务的不同版本之间，操作设置可能存在差异；此外，为了优化您的使用体验，开发者也可能对操作设置进行调整，故如下指引仅供参考，具体操作以您实际产品操作页面为准。

6.1 访问个人信息

正常登录到本服务后， 打开左侧菜单，点击左下角头像到“偏好设置”>“通用”即展示您的个人信息（如名称等）。

6.2 删除对话

  1. 正常登录到本服务；
  2. 打开左侧菜单，选择历史对话；
  3. 长按您要删除的对话记录栏，点击弹出中的“删除”即可以删除对话。

6.3 投诉举报/反馈意见

  1. 正常登录到本服务；
  2. 打开左侧菜单，点击左下角“设置”图标，进入到“偏好设置”>“通用”；
  3. 点击“意见与反馈”，输入投诉举报的相关的内容，点击“提交”；
  4. 也可以通过联系开发者中留下的邮箱，通过邮箱进行反馈。

6.4 获取您的对话副本

  1. 正常登录到本服务；
  2. 打开左侧菜单，点击选择历史对话，或者实时交互生成新的对话内容；
  3. 在需要进行复制的内容上长按，弹出菜单中点击“复制”，即可完成复制。

6.5 注销账号

  1. 正常登录到本服务；
  2. 打开左侧菜单，点击左下角“设置”图标，进入到“偏好设置”>“通用”；
  3. 点击“注销账号”，在弹窗中点击“注销账号”按钮，即可完成注销。

如果您无法通过上述途径和方式行使您的个人信息权利，或要求行使其他法定的个人信息权利，您可以通过本政策“10.联系开发者”中提供的联系方式提出您的请求，开发者将在接到您的请求之日起十五（15）日内或法律法规规定的期限内予以反馈。为保障安全，如您根据本政策向开发者提出请求，开发者将先验证您的个人信息主体身份，然后再处理您的请求。

7. 变更

开发者可能会适时对本政策进行修订。当本政策的条款发生变更时，开发者会在版本更新时向您提示变更后的隐私政策，并向您说明生效日期。如果个人信息的处理目的、处理方式和处理的个人信息种类发生变更的，开发者将重新取得您的同意。

8. 未成年人保护

开发者非常重视对未成年人个人信息的保护。奇境探索服务主要面向成年人。
